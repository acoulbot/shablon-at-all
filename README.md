# Универсальный шаблон интернет-магазина

Полнофункциональный шаблон интернет-магазина без привязки к конкретному бизнесу. Все данные — название, логотип, цвета, контакты, SEO — настраиваются через админ-панель.

## Стек технологий

- **Next.js 16** (App Router, Turbopack)
- **TypeScript**
- **Tailwind CSS 4**
- **Prisma 7** + SQLite (адаптер better-sqlite3, легко мигрируется на PostgreSQL)
- **JWT** аутентификация

## Возможности

### Для покупателей
- Каталог с фильтрами (цена, тип, бренд, цвет) и пагинацией
- Вложенные категории с SEO-URL (`/catalog/parent/child`)
- Карточка товара с фото, отзывами, рекомендациями
- Корзина со штучными товарами и упаковками (скидка за упаковку)
- Оформление заказа (доставка / самовывоз)
- Личный кабинет (заказы, профиль, избранное)
- Сравнение товаров
- Новости / статьи
- Schema.org разметка (Organization, LocalBusiness, Product, BreadcrumbList, NewsArticle)
- PWA manifest, OG Image, SEO метаданные

### Админ-панель (`/admin`)
- Категории, товары, слайдер, новости
- Импорт товаров из Excel/CSV (с дедупликацией)
- Заказы, клиенты, заявки на звонок
- Статистика посещений
- Редактирование страниц сайта (О компании, Доставка, Контакты)
- **Настройки сайта** — название, логотип, фавикон, цвета, контакты, соцсети, SEO, коммерция

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/acoulbot/shablon-at-all.git
cd shablon-at-all

# 2. Установить зависимости (автоматически генерирует Prisma Client)
npm install

# 3. Скопировать .env файл
cp .env.example .env

# 4. Создать БД и применить миграции
npx prisma migrate dev

# 5. Заполнить БД начальными данными (создаёт админа и дефолтные настройки)
npm run seed

# 6. Запустить dev-сервер
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Вход в админ-панель

- **URL:** [http://localhost:3000/admin](http://localhost:3000/admin)
- **Логин:** `admin`
- **Пароль:** `admin123`

> Смените пароль после первого входа (вкладка «Аккаунт»).

## Настройка магазина

После входа в админку откройте вкладку **«⚙️ Настройки сайта»** и заполните:

| Раздел | Поля |
|--------|------|
| Основная информация | Название, описание, ключевые слова, логотип, фавикон |
| Контакты | Телефон, email, адрес, время работы, самовывоз |
| Соцсети | Telegram, ВКонтакте, WhatsApp |
| Цветовая гамма | Основной, акцентный, ошибка, успех, фон (с color picker) |
| SEO | OG Title, OG Description, текст подвала |
| Коммерция | Скидка за упаковку (%), бесплатная доставка от (₽) |

## Переменные окружения (.env)

```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="your-secret-key"
RESEND_API_KEY=""              # Опционально — для email-верификации
RESEND_FROM_EMAIL=""           # Email отправителя
NEXT_PUBLIC_GA_ID=""           # Google Analytics ID
NEXT_PUBLIC_METRIKA_ID=""      # Яндекс.Метрика ID
```

## Структура проекта

```
src/
├── app/
│   ├── admin/          # Админ-панель (все разделы)
│   ├── catalog/        # Каталог с вложенными категориями
│   ├── product/        # Карточка товара
│   ├── api/
│   │   ├── admin/      # API админки (CRUD, настройки, импорт)
│   │   ├── settings/   # Публичный API настроек сайта
│   │   └── user/       # API клиентов (корзина, заказы, профиль)
│   ├── layout.tsx      # Корневой layout (динамические метаданные, Schema.org)
│   └── page.tsx        # Главная страница
├── components/         # React компоненты
│   ├── Header.tsx      # Шапка (динамическое название и лого)
│   ├── Footer.tsx      # Подвал (динамические контакты и соцсети)
│   ├── SchemaOrg.tsx   # Schema.org разметка из настроек
│   └── ...
├── lib/
│   ├── prisma.ts       # Prisma клиент
│   ├── settings.ts     # getSettings() с React.cache()
│   ├── auth.ts         # JWT авторизация
│   └── slugify.ts      # Транслитерация (кириллица → латиница)
└── generated/          # Сгенерированный Prisma клиент (не коммитится)

prisma/
├── schema.prisma       # Схема БД (включая SiteSettings)
├── seed.ts             # Начальные данные
└── migrations/         # Миграции
```

## Деплой

### Production build
```bash
npm run build    # Автоматически запускает prisma generate
npm run start
```

### Миграция на PostgreSQL
1. Измените `provider` в `prisma/schema.prisma` на `"postgresql"`
2. Обновите `DATABASE_URL` в `.env`
3. Запустите `npx prisma migrate dev`
